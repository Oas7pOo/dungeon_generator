# 地牢地图生成器

一个功能强大的地牢地图生成系统，支持多层地图生成、多种建筑区类型和可视化展示。

## 项目结构

```
dungenMap/
├── backend/              # 后端地图生成逻辑
│   ├── main.py          # 后端主入口
│   └── map_logic.py     # 地图管理逻辑
├── frontend/            # 前端可视化界面（Next.js）
├── 地图输出/            # 生成的地图文件（PDF和PNG格式）
├── dungeon.db           # SQLite数据库，存储地图数据
├── 生成地图.py          # 核心地图生成脚本
└── readme.md            # 项目说明文档
```

## 功能特性

### 地图生成
- 支持多层地牢地图生成
- 多种建筑区类型：
  - 矩形建筑区（普通和旋转）
  - 圆形建筑区（圆塔）
  - 多边形建筑区
- 智能碰撞检测，避免建筑区重叠
- 支持跨层建筑区
- 基于概率分布的尺寸生成

### 数据管理
- 使用SQLite数据库存储地图数据
- 支持建筑区属性持久化
- 多层地图信息管理

### 可视化输出
- 生成PDF格式的地图文件
- 生成PNG格式的地图预览
- 分层输出，每层一个文件

## 核心组件

### 建筑区生成器

#### 1. 矩形建筑区生成器
- 生成普通矩形建筑区
- 支持旋转矩形（可指定角度范围）
- 智能放置算法，寻找最佳位置

#### 2. 圆塔建筑区生成器
- 生成圆形建筑区
- 可指定半径范围
- 自动避开障碍物

### 地图管理
- 初始化和管理多层地图
- 获取地图尺寸和层信息
- 检查建筑区重叠

## 使用方法

### 1. 基本地图生成

```python
# 导入地图生成器
from 生成地图 import 矩形建筑区生成器, 圆塔建筑区生成器

# 初始化矩形建筑区生成器
rect_gen = 矩形建筑区生成器("测试矩形", "地牢测试", 0)

# 创建矩形建筑区
rect_gen.create_building_area(
    建筑区名="测试矩形",
    map_name="地牢测试",
    层=1,
    矩形大小=[(10, 10), (30, 30)],
    尝试次数=10
)

# 初始化圆塔建筑区生成器
circle_gen = 圆塔建筑区生成器("测试圆塔", "地牢测试", 0)

# 创建圆塔建筑区
circle_gen.create_building_area(
    建筑区名="测试圆塔",
    map_name="地牢测试",
    层=1,
    半径范围=(5, 15),
    尝试次数=10
)
```

### 2. 生成带角度的矩形

```python
rect_gen.create_building_area(
    建筑区名="旋转矩形",
    map_name="地牢测试",
    层=1,
    矩形大小=[(15, 15), (25, 25)],
    angle=[(-30, 30), 45, 90],  # 角度范围和固定角度
    尝试次数=10
)
```

### 3. 生成跨层建筑

```python
rect_gen.create_building_area(
    建筑区名="跨层建筑",
    map_name="地牢测试",
    层=(1, 3),  # 跨越1-3层
    矩形大小=[(20, 20), (40, 40)],
    尝试次数=10
)
```

## 前端界面

项目包含一个基于Next.js的前端界面，用于可视化展示生成的地图。

### 启动前端

```bash
cd frontend
npm install
npm run dev
```

然后访问 http://localhost:3000 查看地图可视化界面。

## 数据库结构

主要数据库表：

1. **map** - 存储地图基本信息
   - name: 地图名称
   - width: 地图宽度
   - height: 地图高度

2. **building_areas** - 存储建筑区信息
   - name: 建筑区名称
   - map_name: 所属地图
   - layer: 所在层
   - position: 位置坐标
   - type: 建筑区类型（rectangle/circle/polygon）
   - corner: 建筑区角点数据
   - size: 建筑区大小数据
   - area: 建筑区面积

## 地图输出

生成的地图文件会保存在 `地图输出/` 目录下，命名格式为：
- 地牢测试_层1.pdf
- 地牢测试_层1.png
- 地牢测试_层2.pdf
- 地牢测试_层2.png

## 依赖库

- numpy: 数值计算
- shapely: 地理空间几何操作
- sqlite3: 数据库操作
- json: JSON数据处理
- random: 随机数生成

## 扩展开发

### 添加新的建筑区类型

1. 继承 `建筑区生成器` 基类
2. 实现 `create_building_area` 方法
3. 添加特定的形状生成逻辑
4. 实现碰撞检测

### 自定义地图生成算法

可以修改 `生成地图.py` 中的算法逻辑，调整：
- 建筑区尺寸分布
- 放置策略
- 碰撞检测方法

## 注意事项

1. 确保在运行前已安装所有依赖库
2. 首次运行时，系统会自动创建数据库
3. 生成大量建筑区时，可能需要增加尝试次数
4. 跨层建筑区会在所有指定层生成相同的建筑区
